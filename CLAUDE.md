# Project notes for Claude

## Design work (applies to every UI, page, artifact or visual)
- Never design from defaults. Before any design or redesign, run the `design-inspiration`
  skill (`.claude/skills/design-inspiration/SKILL.md`): a wide inspiration sweep across
  Pinterest, Behance, Dribbble, LinkedIn, galleries and non-UI sources (12+ references,
  6+ source types), three written directions, one chosen and justified. Inspiration is to
  inspire, not to duplicate.
- A colour swap is not a redesign. A redesign changes structure, hierarchy and interaction.
- Make data views interactive and linked: hover or tap one value and the matching value on
  every other device highlights with the delta shown.
- Mobile first in fact (44 px targets, drawers, sticky table headers), 4.5:1 contrast,
  every panel states the question it answers, every field says where its number comes from.
- Label data as CONFIRMED (Hamza's measurements), COMMUNITY-REPORTED (reviews), ESTIMATE or PROXY.
